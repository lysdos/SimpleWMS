Pre-flight review findings (handled inline before dispatch):
- Plan used `wms.admin.username` / `wms.jwt.secret` Spring properties but docker-compose
  env vars are `ADMIN_USERNAME` / `JWT_SECRET`. Spring Boot relaxed binding maps
  uppercase env vars to lowercase dotted properties (e.g. `ADMIN_USERNAME` → `admin.username`).
  Resolution: Subagents will use `${admin.username:admin}` / `${admin.password:}` /
  `${jwt.secret:...}` / `${jwt.ttl-hours:24}` in @Value annotations, matching what
  Spring Boot relaxed binding provides. No application.yml edits needed.
